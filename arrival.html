サーバー到着と帰り道

長い旅をへて、小包はついにWebサーバーに届きました。最後の章では、サーバーが封筒を開けて頼みごとを読み、返事を作り、その返事があなたのもとへ戻って、画面に表示されるまでを見ていきます。そして最後に、旅の全体をふりかえります。

9.1封筒を、外側から1枚ずつ開ける

第5章では、データを送り出すときに、係ごとに封筒に入れてラベルを貼りました。受け取った側は、その逆に外側から1枚ずつラベルを読んで、封筒を開けていきます。それぞれの係は、自分のラベルだけを確かめて、中身を次の係に渡します。

9.2Webサーバーの中 ── 置いてあるものを返すか、その場で作るか

頼みごとを受け取ったWebサーバーの仕事は、大きく2つに分かれます。写真やCSSのように置いてあるファイルをそのまま返すことと、ログインした人のページのようにその場でプログラムを動かして作ることです。頼みごとを選んで、サーバーの中の動きを見てみましょう。

Webサーバーのソフトには、Nginx・Apache・LiteSpeed などがあります。W3Techs の調べ（2026年10月）では、サイトの返事に名前が出ているものでは Cloudflare（32%）・Nginx（30%）・Apache（21%）の順でした。Cloudflare が1位なのは、CDNの拠点（第8章）が返事をしているサイトが多いためです。

出典：W3Techs（2026年10月18日に確認）

9.3返事を縮めて送る

返事の本文は、そのまま送るより縮めて（圧縮して）送った方が速く届きます。第1章のリクエストにあった Accept-Encoding: gzip, br は「縮めたものでも受け取れます」という意味でした。下の文を、ブラウザに入っている本物の圧縮の機能で縮めてみましょう。

HTMLやCSSのような文字のファイルは、同じ言葉がくり返し出てくるので、よく縮みます。example.com のページ（577バイト）を実際に取り寄せたところ、gzip で 400バイト、より新しい Brotli（br）で 334バイトになりました（2026年10月18日）。写真や動画は、ファイルの形式そのものがもう縮めてあるので、さらに縮めてもほとんど小さくなりません。

9.4帰り道 ── 同じ旅を、逆向きに

できあがった返事は、行きと同じように、TCPで小分けに → IPとイーサネットで包んで → ルーターからルーターへと旅をして、あなたのPCに戻ります。ラベルの宛先と差出人が入れかわるだけで、仕組みは行きとまったく同じです。

ひとつおもしろいのは、帰り道は行きと同じ道とは限らないことです。それぞれのネットワークが、自分の経路表で「次はどこへ」を決めるので、行きと帰りで別の道を通ることがよくあります。それでも、IPのラベルの宛先さえ正しければ、ちゃんと届きます。

9.5ブラウザが画面を描く

返事が届いても、まだ画面には何も出ません。ブラウザは、届いたHTMLとCSSを読みといて、何を・どこに・どんな見た目で描くかを計算してから、やっと画面に色をぬります。その手順を、1歩ずつ見てみましょう。

9.6ぜんぶで、どれくらいかかった？

ここまでの旅を、時間で並べてみましょう。条件を変えると、どの章の仕組みが効いているかがわかります。

表示の速さには、Google が示している目安（Core Web Vitals）があります。いちばん大きな部分が表示されるまで（LCP）が2.5秒以内、ボタンを押してから画面が反応するまで（INP）が0.2秒以内、読みこみ中に表示がずれる量（CLS）が0.1以下なら「良好」です。ネットワークの旅を短くする工夫は、そのまま使う人の気持ちよさにつながっています。

出典：web.dev「Web Vitals」

9.9まとめ

  • 受け取った側は、イーサネット → IP → TCP → TLS → HTTP の順に、外側から封筒を開ける
  • Webサーバーは、置いてあるファイルを返すか、プログラムでその場で作る（データベースに問い合わせることも）
  • 文字のファイルは gzip や Brotli で縮めて送ると速い
  • 返事は、行きと同じ仕組みで送り返される。帰り道は行きと同じ道とは限らない
  • ブラウザは DOM・CSSOM → レンダーツリー → 配置の計算 → 色ぬり → 重ね合わせ の順に画面を描く
  • DNSの記憶・近くのCDN・HTTP/3 などの工夫が、表示までの時間を短くしている

これで、URLを打ってから画面が出るまでの旅は終わりです。ふだん何気なく開いているページの裏で、世界中の機械が、何十年もかけて積み重ねられた決まりにしたがって、ほんの一瞬のうちにリレーをしています。次にページを開くとき、その旅を少しだけ思い出してもらえたらうれしいです。
